# Lecture 1, Exercise 1 - Get comfortable with a command line text editor

Write your answers to the following numbered questions in a file called `exercise1.txt`. Practice by writing the answers using the text editor that you are writing about.

1. Which text editor are you choosing to use? Use this text editor to answer the questions that follow.
2. How do you create the file `exercise1.txt`?
3. How do you open the `exercise1.txt` file?
4. How do you save your changes to the file?
5. How do you exit the file and return back to your command line prompt in the shell?
6. Create a folder called `exercise1` and move the `exercise1.txt` file into it. What commands did you use?
7. Now how do you open the `exercise1.txt` file?
8. By default, the `rm` command does not ask for confirmation before deleting. Use the man pages in the shell to figure out how to make the command ask before removing files. What is the option you would use?
9. What is the secret animal?

*While the answers to the questions themselves are relatively easy to find by simply looking them up, **the real learning will come from you actually practicing these commands yourself**. While we won’t be able to know whether you’ve really been practicing, this is not for our benefit, it’s for yours.*


## Bonus

Bonus questions are not for credit; if you are bored and speed through the previous exercise in rapid time, then the bonus exercises are for you.

10. If you chose to use nano, explore customizations for nano with the `~/.nanorc` file ([reference documentation](https://www.nano-editor.org/dist/latest/nanorc.5.html)). What commands did you run to create the `.nanorc` file? What settings did you include in it to customize your experience?
    - If you chose a different editor, then explore customizations for that editor.
11. Pick a text editor that you are NOT familiar with - we suggest vim or emacs. Do the same exercise above, but with the unfamiliar editor.
